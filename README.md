# Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment focuses on solving programming problems using TypeScript and Object-Oriented Programming (OOP). It demonstrates my understanding of TypeScript fundamentals, including basic types, optional and default parameters, readonly tuples, interfaces, type narrowing, generics, Promises, and OOP concepts such as classes, inheritance, and access modifiers.

All eight problem solutions are implemented in a single file [Solutions](./solutions.ts).
